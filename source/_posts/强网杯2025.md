## bbjv

先进行代码分析，查看app.jar的结构，在BOOT-INF下找到com.ctf.gateway

分析如下：

这是一个基于Spring Boot的网关应用，核心功能是通过SpEL表达式执行规则检查，并在特定条件下读取并返回flag文件内容。主要组件如下：

    GatewayController暴露/check端点，接收rule参数调用EvaluationService执行SpEL表达式检查用户主目录下的flag.txt文件若文件存在，读取内容并附加到响应中
    EvaluationService使用SpEL解析器执行表达式采用TemplateParserContext支持#{}模板语法
    SpelConfig配置受限的SpEL执行环境使用SimpleEvaluationContext限制功能添加自定义的SecurePropertyAccessor
    SecurePropertyAccessor重写canRead()始终返回false禁止所有属性访问操作
flag在/tmp目录下，所以我们可以利用spel表达式注入漏洞把user.home改一改

```
#{#systemProperties['user.home']='/tmp'}

// 等价于 Java 代码：
System.getProperties().put("user.home", "/tmp");
```

SpEL 解析使用了 `SimpleEvaluationContext` 而非 `StandardEvaluationContext`

用 `SimpleEvaluationContext`阻断了反射属性读取（`SecurePropertyAccessor`）所以无法利用Runtime类来直接进行rce，但Map访问器仍可用；`#systemProperties` 指向 `java.lang.System.getProperties()`，`Properties `类继承自 `Hashtable<Object,Object>`，因此可以用下标写入

payload：

```
->/check?rule=#{#systemProperties['user.home']='/tmp'}
/check?rule=%23%7B%23systemProperties%5B'user.home'%5D%3D'%2Ftmp'%7D
```


- Flask 每次请求时，都会从 HTTP 请求头中取出 `X-User`。
- 这个 `X-User` 是由前端的 **Go Authorizer 代理** 自动添加的。

比如：

- 未登录时：`X-User: anonymous`
- 已登录时：`X-User: 1`（用户ID）

我们发现普通用户注册登录之后没有任何信息，所以要伪造管理员登录。

#### HTTP协议规范漏洞

根据 **RFC 2616 Section 14.10**，`Connection` 头有两个作用：

1. 控制连接持久性
2. 指定在连接关闭时要删除的头部字段

攻击payload

```
Connection: close,X-User
```

这个头告诉服务器：

- `close` - 处理完请求后关闭连接
- `X-User` - 连接关闭时删除 `X-User` 头部

---

## 前置知识

### 匿名类

**匿名类**是PHP 7引入的特性，它允许你在不预先定义类的情况下直接创建类的实例。

基本语法：

```
$object = new class(参数) {
    // 类的属性和方法
    public $property = 'value';
    
    public function method() {
        return 'Hello World';
    }
};
```

这里的参数是构造函数的参数

简单示例：

```
<?php
// 创建一个匿名类实例
$logger = new class('app.log') {
    private $filename;
    
    public function __construct($filename) {
        $this->filename = $filename;
    }
    
    public function log($message) {
        file_put_contents($this->filename, $message . "\n", FILE_APPEND);
    }
};

$logger->log('This is a log message');
```

#### **匿名类的特点：没有类名**

```
$obj = new class {
    public function sayHello() {
        echo "Hello from anonymous class!";
    }
};

echo get_class($obj); 
// 输出：class@anonymous/path/to/file.php0x7f8a3c012345
```

#### 匿名类的实际名称

虽然匿名类没有程序员定义的名称，但PHP内部会生成一个唯一标识符：

```
class@anonymous[文件路径]:[行号]$[序号]
```

或者在某些情况下：

text

```
class@anonymous[文件路径](行号) : eval()'d code:[行号]$[内存地址]
```

### PHP中的函数声明

"声明"指的是**在代码中创建一个新的函数、类、变量等，让程序知道它的存在**。

#### 普通的函数声明

```
// 这是在全局作用域声明一个函数
function readflag() {
    echo "Hello World";
}
```

声明后，你可以在任何地方调用：

```
readflag();  // 输出 "Hello World"
```

#### 在方法内部声明全局函数

```
class SomeClass {
    public function someMethod() {
        // 在方法内部声明全局函数
        function readflag() {
            echo "This is a global function!";
        }
    }
}

// 使用：
$obj = new SomeClass();
$obj->someMethod();  // 必须先调用这个方法！

// 现在才能调用全局函数
readflag();  // 输出 "This is a global function!"
```

### PHP函数调用方法

在 PHP 里，很多东西都可以被当作函数来调用：

    一个普通字符串 "readflag" —— 当作全局函数名去调用。
    一个数组 ["ClassName", "method"] —— 当作 类方法 去调用（等同 ClassName::method()）。
    还有对象实例加方法名 [ $obj, "method" ] 等等。
